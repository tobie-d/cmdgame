# Cmdgame
simple text based RPG made in java

my second java project (a bit more complex than the first)

**Current Version:** `v0.2.0-alpha` | **Status:** in active development (maybe)

# How to play
make sure you have java 25 or higher installed on your  computer 

download 'cmdgame.jar' from the [Latest Release](https://github.com/tobie-d/cmdgame/releases/latest)

open your terminal/cmd prompt in your downloads folder (or wherever you saved it to) and run:

```bash
java -jar cmdgame.jar
